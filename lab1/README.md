# Лабораторная работа 1 — Рисование черепашкой

Простая программа на Python (`turtle`): управление с клавиатуры, включение/выключение следа («хвост»), цвет и толщина линии, границы окна, препятствие и счёт.

Критерии оценивания 5–10 закрыты в одном файле `main.py`.

## Запуск

Нужен Python 3 (стандартная библиотека `turtle`, без pip-зависимостей для самой игры).

```bash
cd GraficaComputationala/lab1
python3 main.py
```

После открытия окна **кликни по нему**, иначе клавиши могут не ловиться.

Тесты геометрии (нужен `pytest`):

```bash
cd GraficaComputationala/lab1
PYTHONPATH=. python3 -m pytest tests/test_geometry.py -v
```

## Управление

| Клавиша | Действие |
|---------|----------|
| **W** / **↑** | Вперёд |
| **S** / **↓** | Назад |
| **A** / **←** | Поворот влево |
| **D** / **→** | Поворот вправо |
| **Space** | Опустить / поднять хвост (рисовать / не рисовать) |
| **C** | Очистить рисунок (стена и счёт остаются) |
| **1–5** | Цвет линии (чёрный, красный, синий, зелёный, оранжевый) |
| **+** / **=** | Толще линия |
| **-** | Тоньше линия |
| **R** | Полный сброс: домой, счёт = 0, **стена в новом месте** |

WASD и стрелки делают одно и то же: вперёд/назад + повороты (без «шага боком»).

## Как это работает (идея)

1. По умолчанию хвост **поднят** — черепашка серая, следа нет.
2. **Space** опускает хвост — черепашка краснее/крупнее, при движении остаётся линия, счёт растёт (+1 за успешный шаг с хвостом).
3. Чёрная рамка — граница поля. У края шаг **обрезается**, за рамку не уехать.
4. Серая **стена** — препятствие. Через неё нельзя пройти ни с поднятым, ни с опущенным хвостом: шаг просто не выполняется. Если хвост **опущен**, дополнительно появляется ошибка и счёт сбрасывается в 0.
5. **R** возвращает черепашку в центр и ставит стену в случайное новое место.

Сверху на экране HUD: счёт, состояние хвоста, цвет, толщина. Внизу — краткая подсказка по клавишам.

## Главные компоненты кода (`main.py`)

### 1. Геометрические функции (без окна)

Чистая логика — её удобно тестировать без GUI.

| Функция | Зачем |
|---------|--------|
| `point_in_rect` | Точка внутри прямоугольника стены? |
| `segment_hits_rect` | Отрезок шага пересекает стену? (или концы внутри) |
| `clamp_step_inside` | Обрезать следующую координату по полуширине/полувысоте окна |
| `_segments_intersect` и др. | Вспомогательные проверки пересечения отрезков |

Координаты стены хранятся как `Rect = (left, bottom, right, top)`.

### 2. Константы

`WINDOW_W` / `WINDOW_H`, `STEP` (длина шага), `TURN` (угол поворота), `COLORS`, пределы толщины пера, размеры препятствия.

### 3. Класс `DrawingApp` — ядро приложения

Всё состояние и реакция на клавиши живут здесь.

**Черепашки turtle:**

| Объект | Роль |
|--------|------|
| `self.artist` | Игрок: двигается и рисует |
| `self.wall` | Рисует серый прямоугольник-препятствие (сама скрыта) |
| `self.border` | Чёрная рамка игрового поля |
| `self.hud` | Только текст: счёт, статус, ошибка, легенда |

**Важные поля состояния:**

- `drawing` — хвост опущен (`True`) или поднят  
- `color_index`, `pen_size`, `score`, `error_msg`  
- `obstacle_rect` — текущие границы стены  
- `half_w` / `half_h` — пределы движения

**Ключевые методы:**

| Метод | Что делает |
|-------|------------|
| `_bind_keys` | Привязка клавиш через `screen.onkey` |
| `_apply_pen_look` | Внешний вид игрока по состоянию хвоста + цвет/толщина |
| `_update_hud` | Перерисовка текстовой панели |
| `_place_obstacle` / `_draw_obstacle` | Случайная позиция стены и её отрисовка |
| `_try_move` | Один шаг: границы → стена (стоп всегда; штраф только с хвостом) → движение / счёт |
| `toggle_pen` | Space: вкл/выкл рисование |
| `clear_drawing` | C: стереть след |
| `set_color` / `pen_thicker` / `pen_thinner` | Цвет и толщина |
| `reset` | R: home + счёт 0 + новая стена |

`screen.tracer(0)` отключает авто-анимацию; после действий вызывается `screen.update()` — картинка обновляется сразу и без мерцания.

### 4. Точка входа

```python
def main() -> None:
    app = DrawingApp()
    app.screen.mainloop()
```

Создаёт приложение и крутит цикл событий turtle, пока окно не закроют.

## Соответствие оценкам

| Оценка | Что реализовано |
|--------|------------------|
| 5 | Движение с клавиатуры; след только после Space |
| 6 | Повороты; повторный Space поднимает хвост; C очищает |
| 7 | Остановка у края; смена цвета 1–5 |
| 8 | Толщина + / - |
| 9 | Вид черепашки меняется (хвост вверх/вниз) |
| 10 | Стена непроходима всегда; касание опущенным хвостом → ошибка + сброс счёта; R меняет позицию стены |

## Пример сценария

1. Стрелками / WASD подъехать к стене — следа нет.  
2. Space — хвост вниз.  
3. Рисовать рядом со стеной — счёт растёт.  
4. Подойти к стене с поднятым хвостом — черепашка останавливается, ошибки нет.  
5. Опустить хвост и коснуться стены — ошибка, счёт 0.  
6. R — старт заново, стена в другом месте.
